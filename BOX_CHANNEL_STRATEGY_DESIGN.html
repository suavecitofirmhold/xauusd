0. 基线定义与一句话策略

一句话：用 1 小时 K 线判断黄金的通道方向（只做顺势），在 15 分钟 K 线上用支撑/压力位的反转 K 线做均值回归入场，固定美元止损 + R 倍数止盈，单笔固定 0.01 手。

  • 文件：D:\workbuddy\tushare\XAUUSD\xauusd策略\xauusd_box_channel_strategy.py
  • 类：BoxChannelStrategy(bt.Strategy)
  • 主循环：next() 逐根 15m bar 决策（相当于"每分钟回测"）
  • 核心思想：大周期定方向 + 小周期找反转点。黄金 15m 上趋势/突破类信号噪声极大（回测证明 ma_cross/boll/donchian 全亏），而箱体支撑/压力均值回归最稳。

4. 核心算法模块

4.1 通道判定 classify_channel()（1h）

closes = self.data1.close[-trend_window:]        # 近 24 根 1h 收盘
slope  = np.polyfit(x, closes, 1)[0]             # 线性回归斜率
rel    = slope / mean(closes)                    # 相对斜率（消除量纲）
mid    = mean(closes)                            # Donchian 中轨（均值近似）
cur    = self.data1.close[0]
if   rel >  rel_slope_thresh and cur >= mid: return "up"
elif rel < -rel_slope_thresh and cur <= mid: return "down"
else:                                          return "range"   # 预热返回 "warmup"

返回 up / down / range / warmup。只有 up 允许做多、down 允许做空；range 与 warmup 一律不交易。

4.2 短期方向过滤 classify_short_direction()（15m）

对近 short_trend_n=20 根 15m 收盘做同样斜率判定，返回 1 / -1 / 0。作用：大周期向上但 15m 加速向下时不抄底；反之不摸顶（避免逆势接刀）。阈值取 rel_slope_thresh * 0.5（15m 窗口短，灵敏度略高）。

4.3 支撑/压力聚类 cluster_levels(data, n)

mids = (highs + lows) / 2.0
counts, edges = np.histogram(mids, bins=cluster_bins, range=(lo, hi))
best  = argmax(counts)                          # 最密集价格带
mask  = (mids in [edges[best], edges[best+1]])
if mask.sum() >= min_k:
    support    = lows[mask].min()               # 密集带内最低 low
    resistance = highs[mask].max()              # 密集带内最高 high
else:
    support, resistance = lo, hi                # 退化为窗口极值（震荡区间）

分别对 15m（short_win）与 1h（long_win）调用，优先用短期，短期缺失则退化为长期。

4.4 反转 K 线确认 detect_reversal(support, resistance)

  • 锤子线（做多）：下影线/整根 ≥ min_wick_ratio 且收阳（c≥o），且价格接近支撑。
  • 上吊线（做空）：上影线/整根 ≥ min_wick_ratio 且收阴（c≤o），且价格接近压力。
  • 吞没：前阴后阳=看涨吞没（做多）；前阳后阴=看跌吞没（做空）。
  • "接近"判定：|c − level| / level < rev_tol × 3。

4.5 入场 / 止损 / 止盈计算

# 做多（上升通道 + 反转 + 下探支撑未跌破）
if l <= support <= c:
    stop   = support - sl_buffer                # 支撑下方外推 sl_buffer 美元
    target = c + r_mult * (c - stop)            # 上方 R 倍风险处止盈
# 做空（下降通道 + 反转 + 上探压力未突破）
if c <= resistance <= h:
    stop   = resistance + sl_buffer
    target = c - r_mult * (stop - c)

5. 策略主流程与流程图

主循环 next() 是一个逐根 bar 的状态机：先处理持仓与挂单，再在无持仓时走"通道闸门 → 多重质量过滤 → 入场"的判定链。任一步不满足即 return（本 bar 不动作）。

6. 关键节点带数值示例

以下示例使用一段虚构但贴近真实的 XAU/USD 行情（单位：美元/盎司），假设当前为上升通道（up），r_mult=1.2、sl_buffer=2.0。

示例 A — 节点③聚类：找支撑/压力

近 short_win=8 根 15m 的 (high+low)/2 分别为：

2386.1, 2386.4, 2385.9, 2386.2, 2386.0, 2386.3, 2385.8, 2386.1

直方图最密集带落在 [2385.8, 2386.4]，落入该带 K 线数 = 8 ≥ min_k=3。取带内 lows.min() 与 highs.max()：

  • support = 2385.20（带内最低 low）
  • resistance = 2398.40（带内最高 high）

若密集带内 K 线数 < min_k，则退化为窗口极值（震荡区间），支撑=窗口最低 low、压力=窗口最高 high。

示例 B — 节点④⑤：上升通道 + 支撑反转 → 做多

当前 15m 根：open=2386.40, high=2386.80, low=2384.90, close=2386.10。

  • 下影线 = min(open,close) − low = 2386.10 − 2384.90 = 1.20；整根 = high−low = 1.90；比例 = 1.20/1.90 = 0.63 ≥ min_wick_ratio(0.6) ✓ 锤子线。
  • 价格接近支撑：|2386.10 − 2385.20| / 2385.20 = 0.00038 < rev_tol×3(0.0045) ✓。
  • 入场形态：low(2384.90) ≤ support(2385.20) ≤ close(2386.10) ✓ 触发做多。

计算：

entry = 2386.10
stop  = support − sl_buffer = 2385.20 − 2.0 = 2383.20
target= entry + r_mult×(entry − stop)
      = 2386.10 + 1.2×(2386.10 − 2383.20)
      = 2386.10 + 1.2×2.90 = 2386.10 + 3.48 = 2389.58
R 倍数 = (target − entry)/(entry − stop) = 3.48 / 2.90 = 1.20  ✓

随后挂 broker 端 SL=2383.20、TP=2389.58，盘中触发其一即平仓（标记 sl 或 tp）。

示例 C — 上升通道 + 压力回落 → 做空（镜像）

当前 15m 根：open=2398.00, high=2400.10, low=2397.60, close=2397.90，压力 resistance=2398.40。

  • 上影线 = high − max(open,close) = 2400.10 − 2398.00 = 2.10；比例 = 2.10/2.50 = 0.84 ≥ 0.6 ✓ 上吊线；收阴（2397.90 < 2398.00）✓。
  • 入场形态：close(2397.90) ≤ resistance(2398.40) ≤ high(2400.10) ✓ 触发做空。
entry = 2397.90
stop  = resistance + sl_buffer = 2398.40 + 2.0 = 2400.40
target= entry − r_mult×(stop − entry)
      = 2397.90 − 1.2×(2400.40 − 2397.90)
      = 2397.90 − 1.2×2.50 = 2397.90 − 3.00 = 2394.90

示例 D — 节点②：震荡不交易

1h 近 24 根收盘回归相对斜率 rel = 0.0003 < rel_slope_thresh(0.0006)，且当前价贴近均值中轨 → 返回 "range"。主循环在 if channel in ("warmup","range"): return 直接退出，本 bar 无任何动作。

示例 E — 节点⑤：短期方向冲突过滤

通道=up，但 15m 近 20 根收盘回归相对斜率 rel = −0.0004 < −rel_slope_thresh×0.5 → short_dir = −1。代码 if channel=="up" and short_dir < 0: return 触发，不抄底（避免在大周期向上、短时加速下跌时接飞刀）。

示例 F — 节点④：隔夜费收取（成本建模）

某周三跨过 TMGM 服务器零点（夏 UTC21:00），持仓 1 手多单（=100 oz）：

usd = oz × swap_long_points × point_value × 3(周三)
    = 100 × (−72.5) × 0.01 × 3 = −21.75 USD   # 从账户扣减

空单则为正（返息）：100 × 30.72 × 0.01 × 3 = +9.22 USD。这正是基线默认 avoid_overnight 关闭、但优化版默认开启"避免隔夜"的原因。
